**4. Implementation plan (derived, not yet written)**
```python
def simpo_loss(self, policy_chosen_logps, policy_rejected_logps):
    beta = self.beta
    gamma = self.gamma_beta_ratio * self.beta
    losses = -F.logsigmoid(beta * policy_chosen_logps - beta * policy_rejected_logps - gamma)
    chosen_rewards = beta * policy_chosen_logps
    rejected_rewards = beta * policy_rejected_logps
    return losses, chosen_rewards, rejected_rewards
```
This matches the paper's Eq. 6 given length-normalized logps, and matches the official SimPO implementation's return contract (per-example losses; rewards = β·logps).
